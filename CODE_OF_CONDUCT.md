# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good faith, critique code rather than people, and keep discussions on
topic. Harassment, insults and personal attacks are not accepted, in issues, pull requests, Discussions or
anywhere else this project is represented.

To report a problem privately, open a report from this repository's **Security** tab (**Report a
vulnerability**) and start the title with "Conduct:". Only the maintainer can see it. You can also use
GitHub's **Report content** option on any comment. Reports are kept confidential. The maintainer may
remove comments or block people who break these rules.
