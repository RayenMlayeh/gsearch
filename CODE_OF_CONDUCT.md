# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good faith, critique code rather than people, and keep discussions on
topic. Harassment, insults and personal attacks are not accepted, in issues, pull requests, Discussions or
anywhere else this project is represented.

To report a problem, contact the maintainer privately at the email address on
[their GitHub profile](https://github.com/RayenMlayeh). Reports are kept confidential. The maintainer may
remove comments or block people who break these rules.
